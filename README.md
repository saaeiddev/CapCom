# CAPCOM // Universe Archive

A cinematic interactive 3D fan-made encyclopedia exploring iconic Capcom game worlds, characters, signature equipment and locations.

## Included in v1

Resident Evil · Devil May Cry · Street Fighter · Monster Hunter · Mega Man · Ace Attorney · Dead Rising · Dragon's Dogma · Ōkami

## Features

- Three.js animated archive core and particle field
- Responsive cinematic interface
- Search and genre filtering
- Game encyclopedia cards
- Character roster
- Character biographies
- Weapons / techniques / equipment archive
- Location index
- Interactive detail modal with tabs
- Optional UI sound feedback
- Mobile responsive layout

## Run

Open `index.html` or serve the repository as a static site. A GitHub Pages workflow is included.
